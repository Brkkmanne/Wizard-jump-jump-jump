To open and run this project on your machine, follow these steps:
0. Install/Update Unity Hub (keep in mind it was built for Unity v6000.2.8f1, it can break the scripts slightly if opened in a newer version)
1. Clone the repository through Git (in your terminal) by running: git clone https://github.com/Brkkmanne/Wizard-jump-jump-jump
   # OR
   Download directly from the "Download ZIP" button on GitHub, by first clicking the green "<> CODE" button at the top of the page. Then extract the folder in your environment.
2. To open it inside Unity Hub, navigate to "Projects" and click the "ADD" dropdown button at the top right, and select "Add project from disk". Then, navigate to where you saved the extracted folder and select it without entering. That's the root folder.
3. Give it a minute to generate some necessary folders. It'll load on its own.
